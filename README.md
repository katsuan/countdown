# ⏳ くろのす（Qronos）〜記念日・カウントダウン〜

名前は「くろのす」。ギリシャ神話の時の神クロノス（Chronos）から（農耕の神 Kronos とは別。Unix の定期実行 cron の名前も chronos から。作成ページの下の「「くろのす」という名前について」に由来を書いている）。英字は Qronos（おくるん＝OQRN・キロっく＝kiloQ と同じ作り方で、「く」を Q にする）。

アイコン（`icon.svg`・`icon-32.png`・`apple-touch-icon.png`・`icon-512.png`・`icon-maskable-512.png`）・横長のロゴ（`logo.svg`）・共有したときの画像（`ogp.png`）は `python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`。GitHub のリポジトリ名は line-share）の `tools/brandkit.py`）。ページと同じむらさきに、右に口の開いた白い C（Chronos の C）。口に砂時計をはめて輪を閉じ、右下のしっぽは真ん中に向けて紙吹雪がはじけるクラッカーで Q。まわりの飾りは置かない。ロゴは Q をアイコンと同じ形にして、r・o・n・o・s をフォント（Jua）で並べる。ホーム画面に追加したとき用に `manifest.webmanifest`。

おくるんのトップの「ほかのツール」（line-share の `data/hub-links.json`）には「くろのす 〜Qronos〜」として、このアイコン付きで載せている。


「あと何日？」「今日で何日目？」をいつでも確かめられるページを作り、[おくるん](https://katsuan.github.io/line-share/)のお知らせカードで LINE に送れる静的サイトです。GitHub Pages でそのまま動きます。

- `create.html` … 種類・名前・日付などを入れてページを作る
- `index.html` … パラメータの内容で、残り・経過をその場で計算して表示する（1秒ごとに更新、当日や節目は紙吹雪）
- `common.js` … 日付の計算、共有 URL とおくるんへ渡す URL の組み立て（URL で受けとる文字は長さを決めて読む）
- `test/` … URL の中身を読む・カレンダーのファイルのテスト（`node --test test/`）
- `style.css` … 共通の見た目（色は `--accent`。ページを開くと選んだ色に置き換わる）


作るページ（`create.html`）の部品（見出しの行・カード・入力欄・ボタン・説明の開閉）は、おくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`。使い方はおくるんの README）。Q キットの色（`--ls-accent` など）は、作る人が選んだ色（`--accent`）につないでいる。年配の方にも読みやすいよう、ラベルと入力欄は Q キットより大きめ。受け取る人のページ（`index.html`）は、お祝いの見た目そのものなので Q キットを使わない。
## 種類

| `type` | 内容 | 表示 |
|---|---|---|
| `until` | その日まで（旅行・イベントなど） | あと○日。時刻つき、または残り1日を切ると時・分・秒も。当日は「今日は ○○！」。過ぎたあとは「○○から ○日たちました」のカウントアップになり、送るカードも 📈 カウントアップ（「○日たちました」のバッジ）に変わる |
| `yearly` | 毎年の記念日（誕生日・結婚記念日など） | 次の○回目の記念日まであと○日、はじまりから○日目 |
| `since` | その日から（付き合った日・禁煙など） | 今日で○日目（はじまりの日が1日目）、○年○か月○日、次の節目（100日目・1000日目・○周年など） |

`type` を省くと、未来の日付は `until`、過去は `since` になります。

## 短いリンク（?z=）

作成ページが作るリンクは `?z=…` の1つにまとめた短い形です（日本語を URL にそのまま入れると1文字9文字になるため、UTF-8 を base64url にして約4文字にする）。

- 中身は `[ボードの名前, 送る人, ひとこと]` と、1件ごとの `[種類, 日付, 名前, 絵文字, 色, ひとこと]`（項目の区切り `\x1f`、行の区切り `\x1e`）
- 種類は `u`／`y`／`s`、色は `0`〜`4`（むらさきは空）、日付は数字だけ（`20261224`・`202612241900`・年なしは `1103`）。決まりの絵文字と後ろの空の項目は省く
- 1件ならその日のページ、2件以上ならボード。くわしくは `common.js` の `packZ`・`unpackZ`
- 下の今までのパラメータのリンクも開けます。開いたページで共有するリンクは短い形に直します

例：1件の記念日で 257 → 131 文字、4件のボードで 437 → 205 文字

## クエリパラメータ（今までの形・手で作るとき）

| キー | 例 | 説明 |
|---|---|---|
| `date` | `2026-12-24` / `2026-12-24T19:00` / `11-03` | 日付（必須）。時刻は任意。毎年の記念日は `11-03` のように年なしでもよい（年齢や「○回目」を出さない。作成ページの「年は出さない」） |
| `type` | `until` / `yearly` / `since` | 種類 |
| `title` | `沖縄旅行` | 名前 |
| `emoji` | `✈️` | 絵文字（省略時は種類ごとの絵文字） |
| `color` | `purple` / `sky` / `leaf` / `sunset` / `berry` / `ff6fa8` | 色 |
| `from` | `たろう` | 送る人の名前（作成ページでは入れなくなった。古いリンクで渡されたときだけ出す） |
| `note` | `プレゼント何にする？` | その日のひとこと（全角15文字まで。ボードでは名前と日数の下に1行で出る） |
| `msg` | `楽しみだね！` | 送るときのひとこと（ページに1つ） |

例：`index.html?type=yearly&date=2020-11-03&title=結婚記念日&emoji=💍&color=berry`

## カレンダーに追加・ボードに戻る

1件の表示ページには、その日の種類に合わせて Google カレンダーの予定作成リンクを出します（`common.js` の `calendarLinks`）。

| 種類 | ボタン |
|---|---|
| その日まで | その日（時刻があればその時刻から1時間、なければ終日）。過ぎた日は出さない |
| 毎年の記念日 | 次の日を毎年くり返す終日の予定 |
| その日から | 次の「○日目」の節目（100・200・…・1000日目など）と、毎年の記念日（くり返し） |

予定のメモには、その日のひとことと、このページのリンクが入ります。

毎年くり返す予定は、リンクに `recur=RRULE:FREQ=YEARLY` を付けていますが、スマホの Google カレンダーのアプリで開くとくり返しが外れて1回だけになることがあります。そのため「📥 ファイルで追加」（`.ics`。`RRULE:FREQ=YEARLY` 入り。`common.js` の `icsText`）も出し、画面に注意書きを添えています。

ボードの行から開いたときだけ、ページ上部に「← 📋 ボードの名前に戻る」を出します（行のリンクに `#b` を付け、ボードの URL はそのタブの sessionStorage に置く。共有するリンクには含めない）。

## 画像で保存

表示ページの「📷 画像で保存」で、同じ内容を 1080×1350 の画像に描いて出します（`snapshot.js`。画面をそのまま写すのではなく canvas に描き直す）。1件なら大きな日数、ボードなら近い順の一覧。画像を長押しで保存、対応する端末では共有メニューからも保存できます。

## ボード（いくつかの日をまとめて表示）

作成ページの「＋ この日をボードに入れて、もう1つ足す」で日を重ねると、1ページに近い順で並ぶボードになります（最大12件）。行を押すとその日だけのページを開きます。

`index.html?name=わが家の記念日&e=yearly~1988-11-03~ママの誕生日~🎂~purple&e=since~2015-06-20~結婚~💞~berry&from=たろう`

- `e` は `種類~日付~名前~絵文字~色~ひとこと`（1件ごと。2件以上でボードになる）
- `name` はボードの名前、`msg`（ひとこと）はボード全体に1つ（作成ページでも日ごとではなく最後に1つ入れる）
- おくるんには、ボードの名前と「あと○日｜🎂 名前」の一覧、「📋 ボードを開く」ボタンのカードで渡す
- ファイルを書きかえたら `common.js`・`style.css` の `?v=` を付け直す（LINE のブラウザが古いファイルを使い続けないように）

## おくるんへの渡し方

カウントダウン（その日まで・毎年の記念日）とカウントアップ（その日から）で、カードの見せ方を変えます。

| | 見出し | バッジ | ボタン |
|---|---|---|---|
| その日まで | ⏳ カウントダウン（日付つき） | あと○日（当日は「今日！」） | ⏳ 最新の残りを見る |
| 毎年の記念日 | 🎂 記念日カウントダウン（毎年 ○月○日） | あと○日（当日は「今日！」、件名は「○回目の…」） | ⏳ 最新の残りを見る |
| その日から | 📈 カウントアップ（○年○月○日から） | ○日目・○年○か月○日（節目の日は件名でお祝い） | 📈 今日で何日目？ |

日数は送ったあとに変わるので、カードには「🕒 ○/○ 時点」と書き、最新はボタンからこのページで見てもらいます。
`https://liff.line.me/<おくるんの LIFF ID>/card/?headerTitle=…&title=…&detail=…&theme=custom&customColor=…&actionLabel=…&actionUrl=<このページ>` の形で、おくるんのお知らせカードに渡します（`common.js` の `buildCardUrl`）。
LINE のボタンのリンクは 1000 文字までなので、作成ページでは共有 URL がそれを超えるときに短くするよう案内します。

## 紹介の窓口

「📤 くろのすを紹介する」（作成ページの下）は、おくるんの `shared/tool-share.js`（`data-tool="qronos"`）。押すとおくるんで紫の紹介カードを作って LINE に送れる（リンクのシェアも選べる）。中身は line-share の `data/hub-links.json` の `key: "qronos"`。

## すくすく（SuQSuQ）とのつながり

赤ちゃん・子どもの日（名前や絵文字が誕生・出産・赤ちゃんに関わるもの）だけ、「🌱 すくすくで写真に入れる」を出し、日付を渡す。生まれた日（「その日から」「毎年の記念日（年あり）」。7 年以内）は `?birth=`、出産予定日（「その日まで」）は `?due=`。付き合った日・結婚記念日などには出さない（すくすくは「生まれて◯日」「妊娠◯週」のツールのため）。すくすくから作ったページ（名前が「はるとの誕生日」「ひなに会える日」など）なら、名前も返す（`&name=`）。すくすくからは「⏳ くろのすで数える」で、このページを開ける。
